# Kunal Exe Coffee

Vite + vanilla JS coffee website. Order WhatsApp ya email se hota hai (Shopify nahi).

## Chalane ka tareeka
```
npm install
npm run dev
```
Build ke liye: `npm run build`

## Videos aur images kahan rakhein

- videos: `hero_espresso_cup.mp4`, `hero_vanilla.mp4`, `brew_hazelnut.mp4`
